    📸 期中考 — WeiGram 社群平台
    Instagram-like 社群媒體網站
    FastAPI + Python

    以影視為主題的全端社群平台（後期發展為通用社群），讓使用者分享貼文、按讚留言、追蹤好友、私訊聊天。採用 FastAPI + SQLAlchemy + Vanilla JS SPA 架構。

    FastAPI SQLAlchemy SQLite JWT bcrypt Vanilla JS SPA i18n 暗色主題
    backend/main.py backend/models.py backend/auth.py backend/schemas.py backend/database.py frontend/index.html frontend/app.js frontend/style.css
  • 使用者認證 — JWT 註冊/登入/登出（30 天有效）
  • 貼文系統 — 圖片上傳、按讚、留言（含刪除）
  • 動態牆 (Feed) / 探索 (Explore) 雙模式
  • 追蹤系統 — 追蹤/取消追蹤
  • 個人檔案 — 頭像、自我介紹、貼文牆、編輯
  • 即時搜尋 — 依使用者名稱搜尋
  • 直接訊息 — 與任何使用者私訊
  • 多國語系 — 繁體中文 / 简体中文 / English
  • 全站暗色主題 UI
    • 📂 資料表設計（SQLAlchemy ORM）
    class User(Base): __tablename__ = "users" id = Column(Integer, primary_key=True) username = Column(String(50), unique=True) email = Column(String(100), unique=True) hashed_password = Column(String(200)) bio = Column(Text, default="") avatar = Column(String(200), default="") class Post(Base): __tablename__ = "posts" id = Column(Integer, primary_key=True) image_url = Column(String(500)) caption = Column(Text) user_id = Column(Integer, ForeignKey("users.id")) # Comment, Like, Follow, Message ...
    🔌 API 端點一覽
    方法路徑說明
    POST/api/register註冊
    POST/api/login登入（回傳 JWT）
    GET/PUT/api/users/me取得/更新個人資料
    GET/api/users/{id}取得使用者資料
    GET/api/users/search/{q}搜尋使用者
    POST/api/posts建立貼文（multipart）
    GET/api/posts / /api/feed取得所有貼文 / 追蹤中動態
    POST/api/posts/{id}/like切換讚
    POST/DELETE/api/posts/{id}/comments新增/刪除留言
    POST/api/follow/{id}切換追蹤
    POST/GET/api/messages傳送/取得訊息
